# Eureka

> 主动运行、自主研究、持续进化的量化研究智能体

Eureka 是一个本地优先的金融研究 Agent，尝试把市场观察、资料研究、策略设计、历史回测和结果追踪放进同一套可审计的研究工作流中。

它目前是一个轻量产品演示，而不是生产级交易平台。项目关注的是金融研究过程能否清晰地运行、保存、复查和继续迭代，不提供实盘交易或账户接入能力。

## Eureka 是什么

Eureka 以金融研究 Agent 为主要入口。用户可以用自然语言提出研究目标，由 Agent 选择合适的工具并组织执行过程，结果在同一会话中持续呈现。

当前产品形态包含交互式终端、桌面工作台和本地 Web 工作台。它们共享同一个本地 Core 和 SQLite 状态，不各自维护独立的业务数据。

## 演示中的主要能力

### 市场观察

- 展示中国期货、A 股和美股行情看板
- 按需读取报价与历史 K 线数据
- 汇总市场情绪、宏观日历和公开新闻信息
- 对闭合 OHLCV 数据执行确定性的价格行为分析

### Agent 研究

- 在对话中接收金融研究问题
- 展示工具调用、执行进度和结构化结果
- 将复合任务组织成可追踪的研究工作流
- 保存带来源和证据关系的研究报告

### 策略与回测

- 创建并保存不可变的策略版本
- 校验策略合同并执行有界历史回测
- 比较策略版本、参数和稳健性测试结果
- 保留策略、参数、数据来源、结果和版本谱系

### 研究资产管理

- 统一查看因子、策略、回测和比较结果
- 支持搜索、标签、收藏、归档和来源跳转
- 从历史资产继续研究，而不是依赖一次性对话内容

## 工作方式

```text
用户研究目标
    ↓
金融研究 Agent
    ↓
行情 / 研究 / 策略 / 回测工具
    ↓
Eureka Core
    ↓
SQLite 会话、任务与研究谱系
    ↓
终端 / Desktop / 本地 Web 工作台
```

Eureka 按需获取市场数据，并只使用短期内存缓存减少重复请求。它不会维护永久的历史行情仓库；会话、工具调用、研究产物、策略版本、回测结果和任务状态则保存在本地 SQLite 中，便于审计和恢复。

## 当前边界

- 当前版本用于验证本地金融研究 Agent 的产品形态
- 回测结果和演示数据不代表策略有效性或未来收益
- 自动研究流程具有明确预算与轮次上限，不是无限自我优化系统
- 不包含券商账户、交易所账户、自动下单或实盘交易能力
- 不面向远程多租户、分布式计算或生产级部署

## 设计原则

- **本地优先**：核心状态和研究记录保存在本机
- **过程可见**：工具调用、工作流状态和结果在界面中持续展示
- **结果可追溯**：研究产物关联来源、参数、版本和执行记录
- **边界明确**：研究分析、历史模拟和真实交易保持严格区分
- **轻量可改**：优先验证完整工作流，避免过早引入复杂基础设施
